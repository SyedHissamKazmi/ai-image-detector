# AI Image Authenticity Detector

A production‑minded machine‑learning portfolio project that analyses images and returns a **probability** of whether they were generated by artificial intelligence.

Built with **FastAPI**, **PyTorch**, **Hugging Face Transformers**, and **Pillow**, this system demonstrates real‑world AI/ML engineering skills:

- Modular detector architecture with two different vision models
- Asynchronous concurrent inference (no event loop blocking)
- Per‑model transparency in API responses
- Robust error handling and graceful degradation
- Comprehensive logging and automated tests
- Evaluation & calibration roadmap

---

## ✨ Features

| Feature | Description |
|--------|-------------|
| **Upload & Analyse** | `POST /analyze` accepts an image and returns a full JSON report |
| **Ensemble AI Detection** | Weighted average of two diverse detectors |
| **Per‑model Transparency** | Response includes individual model probabilities |
| **Dominant Colours** | Top 3 colours extracted from each image |
| **EXIF Metadata** | Camera information and other metadata (when available) |
| **Auto‑Resizing** | Large images automatically reduced to 2048px (configurable) |
| **Background Cleanup** | Temporary uploads deleted automatically after response |
| **Rotating Logs** | Detailed logs in `logs/app.log` with size rotation |
| **Graceful Fallback** | If one model fails, the other still returns a result |

## 🧠 AI Models

### Model 1: Ateeqq / SigLIP
- Hugging Face: [`Ateeqq/ai-vs-human-image-detector`](https://huggingface.co/Ateeqq/ai-vs-human-image-detector)
- Architecture: SigLIP image classifier
- Labels: `ai`, `hum`
- Weights: ~372 MB

### Model 2: wkaandemir / CLIP ViT
- Hugging Face: [`wkaandemir/ai-image-detector`](https://huggingface.co/wkaandemir/ai-image-detector)
- Architecture: CLIP ViT‑B/16 + merged LoRA
- Output: `p(real)` → converted to `p(ai) = 1 - p(real)`
- Weights: ~343 MB

### Ensemble
The final AI probability is a weighted average (currently 50/50) of both models.  
If one model is unavailable, the other still returns a result, and the response indicates which models contributed.

---

## ⚠️ Limitations

> **This detector is probabilistic, not definitive.**  
> It can and will make mistakes, especially on:
> - Highly compressed or low‑resolution images
> - AI generators not present in the training data
> - Artistic or heavily filtered images

Always treat the result as an indicator, not proof.  
Human review is recommended for important decisions.

## 🚀 Quick Start (Local Development)

### Prerequisites
- Windows 10/11, Python 3.12+
- [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) (for PyTorch on Windows)

### 1. Clone and set up environment
```powershell
git clone https://github.com/SyedHissamKazmi/ai-image-detector.git
cd ai-image-detector
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

### 2. Install dependencies
```powershell
# CPU-only PyTorch (Windows)
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

# Other dependencies
python -m pip install -r requirements.txt

# Dev dependencies (for tests)
python -m pip install -r requirements-dev.txt
```

### 3. Configure (optional)
Edit `.env` to adjust file size limits, log paths, model weights, etc.  
Defaults work fine for local development.

### 4. Run the server
```powershell
python -m uvicorn app.main:app --reload
```

### 5. Open API docs
Visit `http://127.0.0.1:8000/docs` and use the `POST /analyze` endpoint.
